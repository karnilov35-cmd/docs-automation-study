<h1 id="_1">Отчет о работе</h1>
<p>Я изучил автоматизацию разработки технической документации по принципу<br>
Docs-as-Code.</p>
<p>Мой сайт: https://ВАШ_ЛОГИН.github.io/docs-automation-study/</p>
<h2 id="_2">Что сделано</h2>
<ol>
<li>Смоделирован «хаос» из трёх файлов с непонятными именами.</li>
<li>Показана потеря версии при копировании и переименовании.</li>
<li>Создан репозиторий <code>docs-automation-study</code> с историей коммитов.</li>
<li>Документация переведена на Markdown.</li>
<li>Сайт собран автоматически из репозитория.</li>
<li>Схема процесса построена текстом в PlantUML.</li>
<li>Справочник API сгенерирован из OpenAPI-спецификации.</li>
<li>Отчёт зафиксирован в репозитории.</li>
</ol>
<h2 id="_3">Вывод</h2>
<p>Документация стала продуктом: у неё есть структура, версии, сборка,<br>
публикация и единый источник истины.</p>
